# Computer Zimmerer

Website von Bernd Zimmerer, Computer Zimmerer, Hannesried 37, 93464 Tiefenbach.

Next.js und Tailwind. Lokal: `npm install`, danach `npm run dev`.

Das Kontaktformular sendet über die Server-Route `/api/contact` mit Resend. Umgebungsvariablen: `RESEND_API_KEY`, `CONTACT_TO`, `CONTACT_FROM`, optional `CONTACT_REPLY_TO`.

Bildnachweise stehen in `IMAGE_CREDITS.md`.
